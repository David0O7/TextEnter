TextEnter

Пользовательский скрипт для Tampermonkey и ScriptCat: шаблоны сообщений, переменные {{date+3}}, тегированные профили и база данных — в любом поле ввода на любом сайте.

Установить скрипт Открыть настройки GitHub
  • Введите /тег в любом поле — шаблон вставится
  • // — дерево папок с шаблонами
  • Переменные: {{name}}, {{date+N}}, {{calc:сумма*0.2}}, случайные выборки
  • Бэкапы, экспорт/импорт JSON, шаринг шаблонов ссылкой
