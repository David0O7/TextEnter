# TextEnter — Templates and Quick Replies

Пользовательский скрипт (userscript) для Tampermonkey и ScriptCat: шаблоны сообщений, быстрые подстановки и персональные данные под рукой в любом текстовом поле.

## Возможности

- **Шаблоны с тегами** — ввод `/тег` в любом поле ввода и выбор шаблона из меню.
- **Меню `//`** — дерево папок с шаблонами (иконки, режимы доменов all/only/except).
- **Переменные** — `{{name}}`, `{{date+3}}`, `{{time}}`, случайные выборки `[[а|б|в]]`, математические выражения, свои переменные.
- **Профили** — тегированные записи о людях и компаниях: `{{поле:тег}}`, выбор человека при вставке.
- **Просмотр перед вставкой** — редактирование дат и полей в превью.
- **Домены** — шаблоны и папки можно ограничить конкретными сайтами.
- **Бэкапы** — последние 10 версий конфига, экспорт/импорт JSON, шаринг шаблонов ссылкой `#textenter=`.
- **Изолированная страница настроек** — Shadow DOM, стили сайтов не мешают.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или [ScriptCat](https://scriptcat.org/).
2. Откройте сырую ссылку на скрипт:
   `https://raw.githubusercontent.com/David0O7/TextEnter/main/TextEnter%20-%20Templates%20and%20Quick%20Replies.user.js`
   — менеджер скриптов предложит установку.
3. Либо создайте новый скрипт в менеджере и вставьте содержимое файла вручную.

## Использование

| Действие | Как |
|---|---|
| Меню шаблонов | Введите `/` в поле ввода |
| Дерево папок | Введите `//` |
| Открыть меню хоткеем | `Ctrl+Shift+K` |
| Настройки | Иконка менеджера скриптов → «TextEnter: Настройки расширения» или `Ctrl+Shift+L` |
| Импорт/экспорт JSON | Меню менеджера скриптов → «TextEnter: Импорт/Экспорт JSON» |

Отладка: в консоли браузера выполните `localStorage.setItem("textenter_debug","1")` и обновите страницу — в консоли появятся логи `[TextEnter]`.

## Приватность

Конфиг хранится **только** в хранилище менеджера скриптов (GM-хранилище) — копии персональных данных не записываются в `localStorage` посещаемых сайтов. Скрипт не отправляет данные ни на какие серверы.

Переименование с Formix: при первом запуске конфиг и бэкапы автоматически переносятся со старых ключей хранилища (`formix_*`) на новые (`textenter_*`). Старые ключи не удаляются — откат на прежнюю версию не потеряет данные.
